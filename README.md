# Java Networking Client

## Project Overview
This project is a Java-based client application developed to demonstrate client-server communication using Java socket programming.

The client connects to a server and exchanges information through network communication.

## Technologies Used
- Java
- Java Socket Programming
- Maven
- Apache NetBeans

## Key Concepts
- Client-server architecture
- Socket connections
- Input and output streams
- Sending and receiving data
- Handling server connections

## Project Structure
The project uses Maven to organise its source code and manage its configuration.

## Learning Outcomes
This project helped develop an understanding of network communication, Java sockets, and how separate applications communicate over a network.
